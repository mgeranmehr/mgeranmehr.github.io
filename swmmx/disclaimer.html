Disclaimer and Engineering Use

Domain knowledge required

swmmx is a programmatic wrapper and toolkit for EPA SWMM. Effective use requires hydrologic and hydraulic knowledge, SWMM input conventions, and understanding of the EPA SWMM engine.

Simulation results should always be validated before use. Professional engineering judgment is required to interpret, verify, and apply outputs generated by this package for design, planning, operations, or regulatory decisions.

The project is actively maintained, but it may contain bugs, errors, unresolved issues, incomplete outputs, or runtime edge cases. Critical calculations should be verified independently. Report reproducible bugs through GitHub Issues.
