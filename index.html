Open-Source Software

swmmx: A Python Toolkit for EPA SWMM Models

I develop swmmx, an open-source Python package for building, editing, running, visualizing, importing, and exporting EPA SWMM models. The package is designed to make SWMM modelling easier, more reproducible, and more accessible for engineers, researchers, and data scientists.

swmmx provides a unified and discoverable API for working with SWMM models directly in Python. Users can create models from scratch, inspect and modify parameters, add and remove network elements, run simulations, step through simulations, plot layouts and results, validate models, and exchange data with CSV, GIS, and Excel formats.

  • Model creation
  • Parameter get/set
  • CSV/GIS import
  • CSV/GIS/Excel export
  • Simulation runs
  • Step-by-step simulation
  • Layout plotting
  • Time-series plotting
  • Profile plotting
  • Model validation
